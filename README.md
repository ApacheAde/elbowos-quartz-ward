# Quartz Ward

Full-colour Python 3 neon tower-lite arcade for ElbowOS.

Slide an amber quartz ward across three vertical lanes.
Pulse mint bolts at rose scarabs and ice wasps before they reach the core.
A / D or arrows shift the ward. Space / click fires.

## Play

```
pip install -r requirements.txt
python3 quartz_ward.py --play
```

## Record a 9:16 reel

```
python3 quartz_ward.py --record
```
